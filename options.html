Babel Gold Drafting settings

Use Local WebGPU transcription, or explicitly select a cloud or Advanced workflow.

Local C-denoise transcription

The accepted speech checkpoint and learned C-denoise punctuation run on this browser's WebGPU. No OpenRouter key or inference backend is needed for transcription. An optional Gold LLM pass can refine the resulting segments. Install and verify the model bundle, then pass a short audio test before using it. Downloads and tests run only when you request them.

Your task audio is not uploaded for local inference. There is no CPU/WASM neural inference or automatic cloud fallback. If WebGPU or the verified bundle is unavailable, Local stops with an actionable error. Cloud transcription is available only by explicitly changing Mode.

Cloud (Simple) transcription

With Babel Helper installed for editor integration, only an OpenRouter key is needed. Microsoft MAI Transcribe 2 (microsoft/mai-transcribe-2) produces verbatim text with native punctuation and word timestamps in the same editor. There is no hidden Gold rewriting pass.

Task audio is sent to OpenRouter and its cloud transcription provider. The estimated price is about $0.10 per audio hour; both audio lanes are billed, so two one-hour lanes cost about $0.20. Provider pricing can change.

Paid transcription runs only when you explicitly use the transcription wand, Helper transcription, or retry action, never when a task page opens. No backend setup or local-model download is required.

Helper text redistribution is a separate, explicitly requested paid text-model action using the same key. MAI transcription does not add Babel-specific vocal-event tags or guarantee Gold rule-pack compliance; review the draft before saving.

After Local transcription, Gold drafting runs when an OpenRouter key is configured and this box is unchecked. This paid pass sends the draft and, when enabled in Advanced settings, audio to the backend.

Advanced workflow

Uses the free hosted L0 service by default and posts to /v1/draft. Enter a self-hosted base URL to override it.

Flex is cheaper and can be slower. Default leaves service tier selection to OpenRouter/provider. Priority is faster and can cost more.

Low preserves the current drafting default. Provider default omits the reasoning parameter and lets OpenRouter choose.

Controls how Babel Helper AI shortcuts use this extension when Gold Drafting is installed.

C-denoise browser bundle v3

Install the accepted GigaAM speech checkpoint plus the learned C-denoise context and denoising graphs. All inference uses WebGPU. The supplier serves only model files and the optional public-domain test sample, not an inference or audio-upload API. Other users' audio is processed here only if you explicitly opt in below.

1. Download and verify the Babel model bundle in this browser.

2. Test with audio no longer than 15 seconds.

Supplied sample: LibriVox, “Aesop's Fables in Russian”, section 01, Public Domain. Source.
